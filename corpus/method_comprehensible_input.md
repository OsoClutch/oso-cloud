# Comprehensible input: one step past what you know

The claim is that language is acquired by understanding messages slightly beyond
current ability — "i+1", where i is what the learner has and +1 is one new
element held up by context they already command. Input far beyond the learner is
noise; input entirely within them teaches nothing.

The hypothesis is contested: most researchers now hold that output and
corrective feedback matter too, which is why speaking aloud and being graded is
part of Lugha rather than listening alone. But the sequencing idea survives the
criticism intact and is the useful part.

## What this means for sequencing a deck

- A new card should introduce **one** unknown thing. A card with a new word, a
  new particle and a new ending is three cards badly stacked.
- Build on what the stage before established. A `structure` card should use
  vocabulary the `survival` stage already taught, so the only new thing is the
  pattern.
- Context carries the +1. A phrase in a situation the learner recognises is
  learnable; the same phrase bare is not.

## Consequence for generated decks

- Order cards so each one is answerable by someone who has done the earlier
  cards in the same deck.
- When generating a deck for a stage, the words already taught in earlier stages
  of that language are the known vocabulary to build on — reuse them
  deliberately rather than avoiding repetition.
